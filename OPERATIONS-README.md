# Veyora operating system — prelaunch index

## Customer path
1. Public homepage → package comparison → plan builder.
2. Customer prepares inquiry and explicitly sends it by email; no automated collection.
3. After a verified purchase, send order confirmation and secure onboarding instructions.
4. Intake → asset rights and claims verification → content calendar → drafts → client review.
5. Written approval → revisions if needed → secure final delivery.
6. Monthly report for Growth/Authority and next-cycle planning.

## Important limitations
All site work is on unpublished feature/interactive-storefront. Shopify products are draft and not purchasable. No authenticated customer portal, secure asset storage, order-triggered email automation, subscription enforcement, or verified checkout integration has been implemented. Customer-facing terms are drafts. Do not mark the business launched.
